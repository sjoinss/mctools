투명 아이템 액자 주기
아이템 액자를 투명하게 만들어서 아이템만 떠 있는 것처럼 보이게 해요. 버전에 따라 명령어 문법이 바뀌었어요.
1.19.4 ~ 1.20.4
구버전 NBT 문법 (EntityTag)
give @p item_frame{EntityTag:{Invisible:1b}}
1.20.5 이상 (컴포넌트 문법)
1.20.5부터 아이템 컴포넌트 방식으로 바뀌어서 entity_data 안에 넣어줘야 해요.
give @p item_frame[entity_data={id:"minecraft:item_frame",Invisible:1b}]
글로우 아이템 액자는 item_frame 대신 glow_item_frame으로 바꾸면 돼요.
특정 엔티티 위치 찾기
선택한 종류의 엔티티가 어디 있는지 좌표로 알려줘요. 가장 가까운 것을 찾아서 그 위치를 채팅으로 표시합니다.
해당 엔티티에게 순간이동해서 위치 확인
가장 가까운 대상 옆으로 순간이동해요. 실행 후 좌표를 F3 화면에서 확인하면 돼요.
좌표를 채팅으로 바로 출력
순간이동 없이, 가장 가까운 대상의 좌표를 채팅창에 숫자로 띄워줘요.
/data 명령어 결과는 실행한 사람에게만 보이는 시스템 메시지로 표시돼요.
플레이어 / 엔티티 크기 변경
1.20.5부터 추가된 scale 속성으로 크기를 바꿔요. 히트박스도 같이 변합니다.
되돌리려면 값을 1로 다시 설정하면 돼요.
마네킹 소환 (1.21.9+)
아머스탠드가 아니라, 플레이어처럼 생긴 NPC 형태의 새 엔티티예요. Copper Age 업데이트(1.21.9)부터 추가됐고, summon 명령어로만 소환할 수 있어요.
summon mannequin ~ ~ ~ {profile:"Notch"}
profile 값에 플레이어 이름을 넣으면 그 사람 스킨을 씌운 마네킹이 소환돼요. 삭제는 근처에서 /kill @e[type=mannequin,limit=1,sort=nearest] 로 하거나 직접 공격해서 없앨 수 있어요.
플레이어 프로필 조회 (fetchprofile)
닉네임이나 UUID로 플레이어의 스킨/UUID 정보를 서버에서 가져와요. 접속 이력이 없어도 조회 가능하고, 결과로 나온 헤드 아이템도 바로 받을 수 있어요.
1.21.9(26.1)부터 추가된 명령어예요. 결과가 채팅에 뜨면 클릭으로 헤드 아이템을 바로 받거나 profile 컴포넌트를 복사할 수 있어요.
그 밖에 알아두면 좋은 명령어
막상 필요할 때 잘 기억이 안 나는 것들 모음이에요.
시간을 낮으로 고정
낮/밤이 자동으로 안 바뀌게 게임규칙을 끄고 시간을 고정해요.
gamerule doDaylightCycle false
날씨 고정 (맑음)
비/눈이 자동으로 안 오게 게임규칙을 끄고 날씨를 맑게 유지해요.
gamerule doWeatherCycle false
인벤토리 비우기
대상의 인벤토리를 전부 비워요.
clear @p
엔티티 이름 지정 + 이름표 숨기기
이름은 있지만 머리 위 이름표는 안 보이게 하고 싶을 때.
data merge entity @e[limit=1,sort=nearest] {CustomName:'{"text":"이름"}',CustomNameVisible:0b}
가장 가까운 구조물 찾기
마을, 요새 등 특정 구조물의 좌표를 알려줘요.
locate structure minecraft:village
village 대신 stronghold, mansion, ancient_city 등으로 바꿀 수 있어요.
특정 위치에 파티클 계속 뿌리기
반복 커맨드 블록에 넣으면 장식/이펙트용으로 계속 파티클이 나와요.
particle minecraft:totem_of_undying ~ ~1 ~ 0.3 0.3 0.3 0.01 20
무한 효과 부여 (예: 야간투시)
infinite로 시간 제한 없이 효과를 유지해요.
effect give @p minecraft:night_vision infinite 0 true
월드보더 크기 설정
플레이 가능 구역을 제한할 때. 숫자는 지름(블록 수)이에요.
worldborder set 6000
