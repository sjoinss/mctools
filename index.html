투명 아이템 액자 주기
아이템 액자를 투명하게 만들어서 아이템만 떠 있는 것처럼 보이게 해요. 버전에 따라 명령어 문법이 바뀌었어요.
1.19.4 ~ 1.20.4
구버전 NBT 문법 (EntityTag)
give @p item_frame{EntityTag:{Invisible:1b}}
1.20.5 이상 (컴포넌트 문법)
1.20.5부터 아이템 컴포넌트 방식으로 바뀌어서 entity_data 안에 넣어줘야 해요.
give @p item_frame[entity_data={id:"minecraft:item_frame",Invisible:1b}]
글로우 아이템 액자는 item_frame 대신 glow_item_frame으로 바꾸면 돼요.

대상
▾

yaw는 -180 ~ 180 사이여야 해요.
pitch는 -90(위) ~ 90(아래) 사이여야 해요.
yaw(좌우 회전): -180 또는 180 = 북쪽, -90 = 동쪽, 0 = 남쪽, 90 = 서쪽을 바라봐요.

게임규칙 (gamerule) 바꾸기
자주 쓰는 게임규칙을 모았어요. 규칙을 고르면 그게 뭘 하는 건지 설명이 뜨고, 값을 정해서 명령어를 만들 수 있어요.
▾
즐겨찾기한 게임규칙
자주 바꾸는 규칙을 눌러서 위 드롭다운에 바로 불러와요.
의자 만들기 (interaction 엔티티)
아머스탠드 대신 interaction 엔티티를 앉는 판정으로 써서, 계단이나 블록 위에 자연스럽게 앉을 수 있게 만드는 방법이에요. 총 3단계로 나뉘어요.
① 의자 자리에 interaction 엔티티 소환
앉을 위치의 중심 좌표에 소환해요. width는 앉는 판정의 가로 폭, height는 높이예요. 기본값(가로 0.9 / 높이 0.1)이면 낮은 계단이나 카펫 위에 앉는 느낌에 잘 맞아요.
width height
width는 0보다 커야 하고 8을 넘을 수 없어요.
height는 0보다 커야 하고 8을 넘을 수 없어요.
~ ~ ~ 부분은 명령어를 실행하는 위치 기준 상대좌표예요. 원하는 좌표로 직접 바꿔도 돼요.
② 이미 소환된 의자 크기 조절
이미 만들어둔 chair 태그 엔티티들의 크기를 한 번에 바꿔요.
width height
하나만 지정해서 바꾸고 싶다면, 먼저 /data get entity @e[tag=chair,limit=1] UUID 로 UUID를 확인한 다음 그 값을 대상으로 data merge entity 명령을 실행하면 돼요.
③ 앉기 구현 (반복 명령블록)
플레이어가 chair 태그 엔티티를 우클릭하면 자동으로 올라타게(앉게) 만들어요. 반복형 커맨드블록에 넣고 계속 켜두세요.
execute as @e[tag=chair] at @s on target run ride @s mount @e[tag=chair,limit=1,sort=nearest]
on target은 방금 누군가 우클릭(상호작용)한 interaction 엔티티만 골라내는 조건이에요.
③-보조. 상호작용 기록 초기화 (연쇄형)
위 반복 명령이 같은 클릭을 계속 인식하지 않도록, 처리한 상호작용 기록을 지워줘요. 위 명령어 바로 뒤에 연쇄형 커맨드블록으로 이어붙이세요.
execute as @e[tag=chair] run data remove entity @s interaction
